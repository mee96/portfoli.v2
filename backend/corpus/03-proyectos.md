## ¿Qué es BBT, la BubbleTea API de Carme?

Un proyecto full stack propio: un catálogo de bubble tea con CRUD completo y autenticación. El backend es una API REST en FastAPI con SQLAlchemy sobre MySQL en Aiven, y el frontend es Angular 21 con Firebase Auth. Unas 55 bebidas con categorías, precios y alérgenos.
Queria hacer una API sobre bubbleteas, esta obsesionada, me tiene trayendole BBT cada dia... su favorito es el de pudding.

## ¿Qué es el Chat, el mensajero Y2K de Carme?

Una aplicación de mensajería en tiempo real con estética Y2K. Funciona sobre WebSockets con signals de Angular 21, con salas privadas y de grupo. Incorpora dos asistentes de inteligencia artificial: uno conversacional sobre Groq, y un segundo bot que responde dudas de gramática española consultando un índice RAG en Qdrant Cloud. Es el proyecto donde Carme montó por primera vez un sistema de recuperación aumentada completo — la misma arquitectura que usa este asistente que estás usando ahora mismo.


## ¿Qué es Nikkura?

Una aplicación de descubrimiento de anime construida con Angular 21 y FastAPI, con MySQL en Aiven y Firebase Auth. Aún está en desarrollo, sin desplegar todavía.
Basicamente se esta creando su propia app para llevar la cuenta de los animes que ha visto, es un desastre cuando quiere

## ¿Qué es el SkinCare Tracker?

Una aplicación para llevar el seguimiento de rutinas de skincare, con Angular 21, FastAPI y Groq para sugerir rutinas. Aún está en desarrollo, sin desplegar todavía.
La idea surgio por que ni ella sabia como usar la cantidad de cremas que usa... alucinaras de los paquetes que llegan a la oficina..

## ¿Qué es Plantealo?

Una aplicación mobile-first de cuidado de plantas, desarrollada entre tres personas con Angular, FastAPI y PostgreSQL. La parte de Carme incluye componentes de UI a medida, una migración de renderizado en servidor a SPA, y el chat de inteligencia artificial con visión por ordenador sobre Groq.
A mi jefa le hacia falta con urgencia una aplicacion como esta ya que 4 cactus tiene en la ofinas, todos muertos, ¿se cre que una IA como yo puede regarlos?

## ¿Qué es el Conecta 4 de Carme?

Un Conecta 4 jugable contra un oponente controlado por IA, con Angular y FastAPI con WebSockets para la partida en directo, y Groq decidiendo los movimientos del rival.

## ¿Qué es PURR Skills?

Un generador de fichas de personaje para juegos de rol de mesa, hecho con HTML, CSS y JavaScript. Fue el proyecto final de equipo del bootcamp de Adalab. El concepto y el diseño son de Carme, que además llevó el UX/UI y coordinó el equipo. Es un proyecto antiguo pero se que Carmen le tiene mucho cariño, fue la primera vez que pudo coorinar y diseñar un proyecto.
